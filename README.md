# Lecture Attendance Tracker 📱

An Android application developed using **Java and XML in Android Studio** to help students record and monitor their lecture attendance.

## ✨ Features
- Student login/demo screen
- Add and manage subjects
- Mark attendance as Present, Absent, or Cancelled
- View attendance history
- Undo the last attendance action
- Calculate attendance percentage
- Save attendance data using SharedPreferences
- Clean blue-and-white user interface

## 🛠️ Technologies Used
- Java
- XML
- Android Studio
- Android SDK
- SharedPreferences

## 🎯 Project Objective
To provide a simple and user-friendly Android application that helps students maintain their attendance records and monitor their attendance percentage.
