PRACTICAL 10 — LECTURE ATTENDANCE TRACKER

This is an Android Studio Java project starter, not a precompiled APK.

FEATURES
- Demo login screen
- Subjects list with add/delete
- Editable attendance target
- Mark Present / Absent / Cancelled
- Overall and subject-wise attendance percentages
- Undo last entry
- Attendance history
- Saves data locally using SharedPreferences

HOW TO BUILD THE APK
1. On the Lenovo laptop, install Android Studio from the official Android Developers website.
2. Extract this ZIP file.
3. In Android Studio choose Open, then select the extracted Practical10_AttendanceTracker folder.
4. Allow Gradle sync and install any SDK components Android Studio requests.
5. Choose Build > Build Bundle(s) / APK(s) > Build APK(s).
6. When the build finishes, click Locate. The APK is normally:
   app/build/outputs/apk/debug/app-debug.apk
7. Transfer that APK to your Android phone and install it for testing. Keep the source project too.

NOTES
- Login is a demonstration screen; it does not authenticate a real account.
- This project requires Android Studio/Android SDK to compile. No APK is included in this ZIP.
- If Gradle sync fails, check the error shown in Android Studio and use its recommended SDK/Gradle setup.
